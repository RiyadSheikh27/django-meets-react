## Important Technical Notes

### Tailwind CSS v4
Previously, Tailwind CSS v3 required installing `tailwindcss`, `postcss`, and `autoprefixer`, running `npx tailwindcss init -p`, and configuring the `content` array in `tailwind.config.js`.

With Tailwind CSS v4 and Vite, the setup is simpler:
- Install `tailwindcss` and `@tailwindcss/vite`.
- Add the Tailwind plugin to `vite.config.js`.
- Import Tailwind CSS using `@import "tailwindcss";` in the main CSS file.
- Source files are automatically detected, so the `content` array is no longer required.
- Custom design tokens and theme configurations are defined using the `@theme` directive directly in CSS instead of `tailwind.config.js`.

The theme configuration will be covered in Phase 1.

### Vite 8
Vite 8 requires Node.js `20.19+` or `22.12+`. Make sure your installed Node.js version meets this requirement before starting the project.

Check your version using:

```bash
node -v
```

### React
The project will use the React version provided by the Vite setup. Rather than manually specifying a version, we will use the version generated by `npm create vite` to ensure compatibility.
